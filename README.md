（3）工夫した点・こだわった点
アイデア:じゃんけんの起源を調べて見ると大変興味深く。:fist:

現在の「グーチョキパー」は大戦後にアメリカのRock, Paper, Scissors→日本に普及したものと勝手に思っていたが、　　　　（留学中アメリカの友達にそう教わった）、調べると実は逆で日本から欧米に広がった文化だそう。　　　　　　　　　　　　　明治時代初期に日本に滞在したアメリカ人学者ウィリアム・グリフィスが、著書で日本の「石拳（じゃんけん）」のルール（石、ハサミ、紙/風呂敷）を紹介していたそうです。
さらにルーツを探ると、現在のじゃんけんなるものは江戸時代から存在し、それが「東八拳」と呼ばれるものだそう。
　　手の形やルールは違うが基本的にある手よりある手が強いという基本規則は不変。
